# Player guide: tickets and hidden attractions

The original disc has no manual. Its README only says that clearing the mini-games unlocks hidden content.
This guide comes from the game's own scripts.

## Which attractions give tickets

There are **5 tickets**, one for each of the 5 mini-games. The other attractions never give a ticket:
the tarot reading, Mark's gallery, karaoke, the principal's office, the stress check, the Persona check
and the leader test.

| Attraction (hub) | How to win the ticket | Unlocks |
|---|---|---|
| Ms. Saeko's floor-mopping race (gym) | Win the race | Yukino's Photo Exhibition |
| Reiji & Brown's magic (toilets) | Guess which toilet Brown is hiding in | Ayase's MD Collection |
| Toro's turtle hockey (cafeteria) | Be first to 10 goals | Kurouri's Spell Card Collection |
| Vice Principal Hanya's shooting gallery | Hit 13 frogs, without shooting any of the pests | Butler Yamaoka's Secret VTR Collection |
| Maki's puzzle (art room) | Finish the 15-puzzle before all the timer lamps go out | Trish's dress-up |

The hub's "Tickets" counter shows how many tickets you have.

## Using the tickets

1. In the hub, go to the **principal's office**.
2. If you have at least one ticket, Principal Oishi asks: *"Have you seen everything in the school?
   If you like, I would be happy to show you around."* Answer **Yes**.
   (Without a ticket, the principal offers to explain the CD's contents instead.)
3. Pick a hidden attraction. Only the ones you have a ticket for can be clicked.

A ticket is not used up: you can go back to its hidden attraction as often as you like.

## Tickets are not saved

The game keeps tickets in memory only. **Quitting the program loses every ticket**, so win and use them
in the same session.
